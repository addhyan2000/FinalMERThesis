# ⚠️ `literature_baselines.csv` IS PLACEHOLDER DATA — DO NOT CITE IT

**Nothing in `literature_baselines.csv` is a verified published result, and nothing derived
from it may appear in the thesis.** The same applies to the `literature` rows of the
generated `results/literature_comparison.csv`.

## What is wrong with it

| Row | Problem |
|---|---|
| `Li et al. 2018 (STSTNet)` | **Misattributed and mis-scored.** STSTNet is Liong, Gan, See, Khor & Huang (FG 2019) — bibliography key `liong2019b`, not "Li et al. 2018". MEGC 2019 Table IV reports it at **0.8382 UF1 / 0.8686 UAR** on the CASME II subset, not the 0.63 recorded here. |
| `Vivian et al. 2019 (ME recognition survey)` | **Not a real citation.** Appears in no `BIBLIOGRAPHY.md` entry. Its own note says "Illustrative — verify against paper". |
| `Example Transformer MER` | **A literal placeholder.** Its own note says "Replace with exact paper client shares". |
| `Target dissertation goal` | A client target, not a result of any kind. |

Two further defects affect every row: the `accuracy` column is not UF1, so these values are not
comparable with the MEGC figures the thesis uses; and `compare_with_literature.py:56` hard-codes
`validation: "holdout"` onto this project's rows, which were produced under **LOSO**, not holdout.

## What it already caused

These rows were plotted as **Figure 5.8** of the thesis, under a legend reading "published
literature (LOSO)" and a caption claiming they were MEGC 2019 CASME II subset results. A bar
labelled "Example Transformer MER" appeared in a submitted results chapter. The figure is now
regenerated by `tools/thesis_fig_regen.py` from MEGC 2019 Table IV instead.

`LOSO_Validation_Report.md` also builds claims on this file — notably "Every configuration beats
the published literature" (line 32), which rests on the placeholder 0.65. That report has not
been corrected; treat its literature comparisons as void.

## What to use instead

The seven verified CASME II-subset UF1 values from MEGC 2019 Table IV, reproduced as **Table 5.8**
of the thesis and **Table 3.6** of Chapter 3, both checked cell-by-cell against
`docs/megc-2019-the-second-facial-micro-expressions-grand-challenge.pdf`. They are also encoded in
`tools/thesis_fig_regen.py` as `MEGC_UF1`.

The file is kept rather than deleted because `tools/loso_report_collect.py` and
`tools/compare_with_literature.py` still read it, and because the historical reports were built
from it. The `reference` fields have been relabelled so that anything plotting them now renders
the warning on the chart itself.
